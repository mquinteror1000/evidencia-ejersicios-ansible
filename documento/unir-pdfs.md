## Unir pdf con pdfunite
#### Paquete para debian
```shellsession
sudo apt update && sudo apt install poppler-utils
```

#### paquete para fedora
```shellsession
sudo dnf install poppler-utils
```

#### Estos pdf e unieron asi
```bash
pdfunite portada.pdf parte-1-repaso-ssh.pdf parte-2-ansible.pdf parte-3-ansible-paybooks.pdf salida-tarea-ejersicios.pdf
```
